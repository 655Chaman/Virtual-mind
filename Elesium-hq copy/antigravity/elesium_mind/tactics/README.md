## 🛠 How to Use

1. **Adding a new prompt?** → Add it to `prompt_templates.md` with the next number
2. **Adding a new workflow?** → Create `workflows/0X_name.md` and link it here
3. **Changed tools?** → Update `preferences.md` first, then update affected workflows
